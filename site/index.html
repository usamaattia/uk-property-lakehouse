Method. Price Paid Data is published as add / change / delete records. The pipeline lands raw files (bronze), applies the changes to one clean row per transaction (silver), then builds these statistics (gold). The newest months are left out because sales take weeks to be registered. Medians, not means, because a few very expensive homes skew averages.
